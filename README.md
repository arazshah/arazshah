### About

I have spent more than 12 years building software where maps, data and backend services meet: spatial databases, risk-assessment and claims platforms, Sensor Web systems, and, more recently, natural-language-to-map applications driven by LLMs.

- **Now:** geospatial backend services, GeoAI pipelines and MCP servers at **Spatial Science Innovators**, and senior backend engineering at **Alborz Insurance**, where I have built geospatial risk assessment, claims mapping and fraud-pattern analysis since 2016.
- **Focus:** Python (Django, FastAPI), PostgreSQL/PostGIS, LLM orchestration, plugin-based architectures, and clean APIs that stay maintainable as they grow.
- **Community:** recognised as an [OSGeo Advocate](https://wiki.osgeo.org/wiki/OSGeo_Advocate#Araz_ShahKarami). I teach GIS, backend and AI topics in Persian and speak at Linux and open-source community events.
